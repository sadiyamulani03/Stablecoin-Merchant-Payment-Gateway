## Git commit conventions

- Never add `Co-Authored-By:`, `Signed-off-by:`, or any AI/agent attribution trailer to commit messages.
- Do not add "Generated with ...", "Created by ...", session links, badges, or emojis to commit messages or pull request descriptions.
- Do not mention the tool, model, or vendor name anywhere in commit messages, PR titles/descriptions, or code comments.
- Use only the developer's identity (name and email) as author and committer.
- Do not add `Co-Authored-By: @codebuff-team` or any other agent attribution to commits.
